What is Contrast?

Contrast refers to the visual difference between two elements, such as color, size, shape, or texture. Designers use contrast to guide the user's eye, make important elements stand out, and create visual hierarchy.

Good vs. Bad Design Examples

Color contrast:

Color contrast is the difference in brightness between foreground and background colors.

Size contrast:

When combining shapes, each of a different size, we create size contrast and emphasize that the larger one is more important.

Font contrast:

Font contrast refers to the intentional use of varied sizes, weights, and colors within a text to create a visual hierarchy and enhance readability.
